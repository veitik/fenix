# Руководство по развертыванию сайта СК ФЕНИКС (Next.js)

Это пошаговое руководство описывает процесс переноса вашего нового сайта на базе Next.js на виртуальный сервер (VPS) от it-garage и привязки к нему домена от Namecheap.

---

## Шаг 1: Привязка домена к серверу (Namecheap)

Сначала нужно сказать вашему домену, на каком сервере находится сайт.
1. Узнайте **IP-адрес** вашего сервера (выдается провайдером it-garage после покупки). Он выглядит примерно так: `192.168.1.50`.
2. Зайдите в панель управления **Namecheap** -> Domain List -> выберите ваш домен и нажмите **Manage**.
3. Перейдите во вкладку **Advanced DNS**.
4. Добавьте или измените две записи:
   * **Тип (Type):** `A Record` | **Хост (Host):** `@` | **Значение (Value):** `Ваш_IP_Адрес_Сервера`
   * **Тип (Type):** `A Record` | **Хост (Host):** `www` | **Значение (Value):** `Ваш_IP_Адрес_Сервера`
5. Сохраните изменения. Обновление DNS может занять от 15 минут до нескольких часов.

---

## Шаг 2: Подготовка сервера (it-garage)

Подключитесь к вашему серверу через SSH (например, через программу PuTTY или встроенный терминал Windows/Mac).
Команда выглядит так: `ssh root@Ваш_IP_Адрес_Сервера`

Вам нужно установить Node.js, Nginx и PM2. Выполните следующие команды по очереди:

```bash
# Обновляем систему
sudo apt update && sudo apt upgrade -y

# Устанавливаем Node.js (версия 20) и npm
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# Устанавливаем Nginx (веб-сервер)
sudo apt install nginx -y

# Устанавливаем PM2 (менеджер процессов, чтобы сайт работал вечно)
sudo npm install -g pm2
```

## Шаг 3: Перенос кода на сервер

Вы можете перенести код с помощью GitHub или просто скопировать файлы.

### Вариант: Загрузка через GitHub (рекомендуется)
```bash
# Переходим в папку, где будут лежать сайты
cd /var/www/

# Скачиваем код (замените ссылку на свою)
git clone https://github.com/ВАШ_АККАУНТ/ВАШ_РЕПОЗИТОРИЙ.git
# Переходим в папку проекта
cd ВАШ_РЕПОЗИТОРИЙ
```

---

## Шаг 4: Запуск сайта (Next.js)

Внутри папки с вашим проектом на сервере выполните:

```bash
# Устанавливаем зависимости
npm install

# Собираем готовую версию сайта
npm run build

# Запускаем сайт в фоновом режиме с помощью PM2
pm2 start npm --name "sk-fenix" -- run start

# Сохраняем настройки PM2, чтобы сайт включался сам после перезагрузки сервера
pm2 save
pm2 startup
```
*Теперь ваш сайт работает на сервере на порту 3000.*

---

## Шаг 5: Настройка Nginx (чтобы сайт открывался по домену без порта)

Нужно настроить Nginx, чтобы он принимал запросы с вашего домена и передавал их на порт 3000.

1. Открываем файл конфигурации:
```bash
sudo nano /etc/nginx/sites-available/sk-fenix
```

2. Вставляем следующий код (замените `ВАШ_ДОМЕН.ru` на ваш реальный домен):
```nginx
server {
    listen 80;
    server_name ВАШ_ДОМЕН.ru www.ВАШ_ДОМЕН.ru;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

3. Сохраняем (`Ctrl+O`, `Enter`) и закрываем (`Ctrl+X`).

4. Включаем сайт и перезапускаем Nginx:
```bash
sudo ln -s /etc/nginx/sites-available/sk-fenix /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx
```

---

## Шаг 6: Бесплатный SSL-сертификат (HTTPS)

Чтобы сайт был безопасным (с замочком) и открывался по `https`, установим бесплатный сертификат Let's Encrypt:

```bash
sudo apt install certbot python3-certbot-nginx -y
sudo certbot --nginx -d ВАШ_ДОМЕН.ru -d www.ВАШ_ДОМЕН.ru
```
Во время установки введите свой email и согласитесь с правилами. Выберите перенаправление (Redirect) всех запросов на HTTPS.

---

**Готово!** Ваш сайт должен открываться по вашему доменному имени.
Если вы захотите обновить сайт в будущем, вам нужно будет зайти на сервер, выполнить `git pull` (чтобы получить новый код), `npm run build` и `pm2 restart sk-fenix`.
